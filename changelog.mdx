## Upgrade Instructions

Follow these steps to upgrade your Applicious instance safely.

<Steps>
  <Step title="Backup Data" icon="database">
    Create a full backup of your current installation.

````bash
pg_dump -U youruser applicious_db > applicious_backup_$(date +%Y%m%d).sql
````
  </Step>
  <Step title="Update Package" icon="download">
    Install the latest version using your package manager.

    <CodeGroup tabs="npm,yarn">
````bash
npm install applicious@latest
````
````bash
yarn add applicious@latest
````
    </CodeGroup>
  </Step>
  <Step title="Run Migrations" icon="settings">
    Execute database migrations.

````bash
npx applicious migrate
````
  </Step>
  <Step title="Restart Services" icon="refresh-cw">
    Restart your applicious services and verify functionality.
  </Step>
</Steps>

<Callout kind="tip">
  Test in a staging environment first. Review migration notes in each release for potential impacts.
</Callout>
